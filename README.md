# שטראוס · מוקד המכירות · יחידה 01 – תפיסת תפקיד והיכרות

לומדת HTML ליחידה 01 בתכנית ההכשרה של מוקדני המכירות בשטראוס, לפי התסריט המאושר.

- קובץ אחד עצמאי: `index.html` (גופני Strauss, תמונות וצלילים מוטמעים בקובץ).
- במה 1200×675, מותאמת לכל גודל מסך.
- 24 מסכים: פתיחה, "אני מאמין", התפקיד, היכרות עם שטראוס והלקוחות, שלושה מוקדים, יום במשמרת, נהלים, איחורים, חופשה, התנהלות במשמרת, סיכום, תרגול מסכם וסיום.
- בכל מסך הערות הפקה (`data-note`) לקראת ההמרה ל-Storyline.

לצפייה: פותחים את `index.html` בדפדפן.
